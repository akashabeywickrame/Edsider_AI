A labelled form control: text input, text area (question serif), or select, with optional help text.

**Consumer provides:** `label`, `as` (`input` / `textarea` / `select`), `options` for select, optional `placeholder`, `value`, `help`, `rows`, `id`.

- Question text is always a text area in the `body-lg` style, so what a person types looks like how it will be shown.
