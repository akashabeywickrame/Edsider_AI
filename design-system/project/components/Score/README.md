Similarity as a whole-number percentage over a track showing the band thresholds (0.85, 0.92), with the pre-guard raw score struck through when a guard lowered it.

**Consumer provides:** `score` (0-1). Optional: `raw`, `thresholds` (default `[0.85, 0.92]`; pass `[0.95]` on the within-paper and cross-passage views), `min` (track start, default 0.70), `legend` (false hides the axis labels).

- Percent, no decimals: "97% similar". Raw decimals (0.977) belong in the `data` mono style in tables and exports only.
- The ticks are the argument: real duplicates and look-alikes overlap in score, so show where the line was drawn.
