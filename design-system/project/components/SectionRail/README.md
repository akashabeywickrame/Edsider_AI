A floating vertical pill of icon buttons for jumping between sections of a long page (.section-rail) - Paper intake and Duplicates within a paper.

**Consumer provides:** `items` (`[{id, icon, label}]`), optional `active`, `label` for the list.

- Every button has an `aria-label` and a tooltip; the icon never stands alone for a screen reader.
- Fixed 22px from the left edge, vertically centred. Hide it below 900px.
