The language of a paper or question, as the site shows it: Sinhala green, Tamil purple, English blue, each written in its own script.

**Consumer provides:** `lang` (`si`, `ta`, `en`), optional `children`.

- These are the brand's own accent pairs and sit below 4.5:1 for small text (kept exact); the bold weight and the script itself carry the meaning.
- Shown automatically on a `QuestionCard` whose `lang` is not English.
