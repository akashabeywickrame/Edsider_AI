An inline message: `info` (neutral), `success`, `warning`, `error`. Replaces `st.info` / `st.success` / `st.warning` / `st.error`.

**Consumer provides:** `tone`, optional `title`, `children`.

- Say what happened and what to do next, in one or two sentences: "3 question(s) still not marked reviewed."
- Errors quote the real cause (the database message) in a code block rather than "Something went wrong".
